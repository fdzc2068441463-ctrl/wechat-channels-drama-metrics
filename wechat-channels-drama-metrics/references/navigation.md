# 视频号助手站点导航与页面细节

开始采集前先读本文，用于在页面上稳定定位。页面改版后以下信息可能变化，以实际可见内容为准；但「图标列含义与顺序」如与正文冲突，以实际页面为准并回写更新本文件。

## 站点与登录
- 平台入口：https://channels.weixin.qq.com/platform/
- 登录：微信扫码。已登录时首页能看到当前视频号名称与「视频号ID: xxx」。账号必须是拥有待采集短剧的视频号（对照清单“剧场名”）。
- 会话不跨机器、不跨浏览器会话保留：新环境都要让用户重新扫码。

## 目标路径
左侧一级菜单为：首页 / 内容管理 / 互动管理 / 直播 / **收入与服务** / 带货中心 / 数据中心 / 设置。
1. 点「收入与服务」会展开二级菜单：收入权益 / 原创保护记录 / 加热工具 / **剧集管理**。
2. 点「剧集管理」→ 页面 URL 形如 `https://channels.weixin.qq.com/platform/playlet`，标题「剧集列表 (总数)」。

## 剧集列表页
- 表格列：剧集名称 | 视频数 | 变现类型 | 上架时间 | 状态 | 操作；每行「操作」里是 `置顶` / `管理` 链接。
- 定位某部剧：页面顶部有搜索框（placeholder / 可访问名「搜索剧名」）；输入剧名回车或点搜索。若搜索不生效，直接在当前页表格里按剧名文本定位（目标剧通常就在前几页）。
- 进入详情：点该剧名所在行的「管理」链接。

## 剧集详情页
- URL 形如 `https://channels.weixin.qq.com/platform/playlet/playlet-detail?id=<剧集ID>`；面包屑「剧集管理 / 剧集详情」。
- 上部为剧集信息（剧名、简介、备案号、变现类型）。
- 页签：`剧集 (N)` / 评论 / 弹幕。本 skill 只读「剧集」页签。
- 剧集列表默认每页约 10 集，第 1 页通常已含第 1–5 集；底部有页码与「下一页」。若需要第 N 集而它不在当前页，翻页/跳页。
- 单集行可见文本形态（示例）：
  `卖掉公司那天，我遇见了她-第1集 审核已通过 免费试看 195 0 0 1`
  集名后依次是：审核状态（如“审核已通过”）、是否试看（如“免费试看”），然后是 **4 个数字**。
- **这 4 个数字没有文字表头**，只有图标列，从左到右为：👁 播放量、❤️ 喜欢量、▭ 评论量、👍 点赞量。抓取时严格按此顺序记数。
- 数字为页面实时数据，可能变化；只读取当前显示值。

## 读取技巧
- 页面正文在 wujie iframe 里：用页面级 `getByText / getByRole / locator` 或无障碍树都能读到正文；直接对顶层 `document.body` 求值只会得到左侧导航。
- 读某集数字：定位包含「剧名-第K集」的行/容器，取其文本，取“免费试看”之后按空白拆出的前 4 个数字。
- 若某行只有集名没有数字，说明该行数据未加载：先滚动使其进入视口并等待，再读；不要补 0。
- 需要多部剧时，每部采完点面包屑/左侧「剧集管理」返回列表，再处理下一部。

## 环境/浏览器差异（换电脑执行时）
- 使用当前环境提供的浏览器自动化工具打开站点即可；不假设已有打开的标签页。
- 页面元素可能因语言/缩放变化，优先按文本（中文）定位。
- 模型若是纯文本（如 DeepSeek），不要依赖截图，全部用文本/DOM/无障碍信息操作。
