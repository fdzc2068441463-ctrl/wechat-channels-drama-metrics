# 视频号短剧「前 N 集」数据采集

把视频号助手「剧集管理」里的每部短剧前 N 集（默认 N=5）播放数据抓下来，按「视频号 + 短剧」汇总成 Excel。适合「把某几部短剧前几集数据导成表格」这类重复任务。

## 关键口径（页面事实，勿擅自更改）
剧集详情里每集一行，末尾 4 个数字对应 4 个只有图标、**没有文字表头**的指标列，从左到右固定为：

| 图标 | 指标 |
|---|---|
| 👁 眼睛 | 播放量 |
| ❤️ 爱心 | 喜欢量 |
| ▭ 长方形 | 评论量 |
| 👍 大拇指 | 点赞量 |

单集行在 DOM / 无障碍文本里的典型形态（数字顺序即上表顺序）：
`剧名-第1集 审核已通过 免费试看 195 0 0 1`

不要臆造列名（如“收藏量”），不要调整这 4 个数字的顺序。

## 输入与输出
- **输入清单（Excel）**：默认取桌面 `新建 XLSX 工作表.xlsx`，表头至少含 `剧场名`、`剧名`，一行一部剧；用户给了别的路径/文件则以用户为准。若清单为空或找不到，先向用户确认。
- **输出 Excel**：默认存到桌面；命名建议 `视频号剧集_前N集数据_<视频号>_<剧名>_<yyyyMMdd>.xlsx`。含两个工作表：
  - `前N集汇总`：按 视频号+剧名 一行，含 前N集 播放/喜欢/评论/点赞 合计、收录集数、抓取时间。
  - `前N集明细`：逐集一行（集数、播放量、喜欢量、评论量、点赞量）。

## 执行流程
1. **确认输入**：读取清单 Excel，得到 (剧场名, 剧名) 列表与目标集数 N（默认 5）。若用户没给文件，默认按上面的路径找；找不到就询问。
2. **打开并登录**：在浏览器打开 https://channels.weixin.qq.com/platform/ 。若未登录，请用户用微信扫码，并确认当前账号就是拥有这些短剧的视频号（页面会显示视频号名称与 ID，须与清单里的“剧场名”对应）。未登录/账号不符时停下来，不要继续。
3. **进入剧集管理**：左侧菜单「收入与服务」→ 展开后点「剧集管理」。
4. **逐部剧采集**：对清单里每一部剧，先阅读 [references/navigation.md](references/navigation.md) 中的页面细节，然后：
   - 搜索或定位到该剧名所在行 → 点该行「管理」进入「剧集详情」；
   - 在「剧集」页签下，确保第 1..N 集的行都已渲染出数字（默认第 1 页即含前 5 集；若行未加载就滚动/翻页，别在空数据上硬读）；
   - 读取每集末尾的 4 个数字，按上面口径记为 播放量/喜欢量/评论量/点赞量；
   - 记录视频号名称、视频号 ID、剧集名称、剧集 ID（详情页 URL 里的 `id=` 参数），然后返回剧集管理列表处理下一部。
5. **生成 Excel**：把采集结果写成 JSON，调用 `scripts/build_drama_excel.py --detail <json> --out <输出路径>` 生成工作簿（脚本会按 视频号+剧名 汇总并排版两个工作表）。
6. **校验交付**：重新读回生成的 Excel，逐项核对每个数字与页面读取值一致；输出路径告诉用户。数据是页面实时值，把抓取时间一并写入。

## 采集技术要点
- 优先用浏览器 DOM 快照 / 无障碍文本 / `getByText` 等方式按文本定位与读数，不要靠截图猜（纯文本模型如 DeepSeek 看不了截图）。
- 该后台是微前端（wujie iframe）页面：顶层 DOM 只能看到左侧导航，正文在 iframe 内；页面级 `getByRole/getByText/locator` 通常能穿透，若拿不到正文，改用无障碍树（AX）读取。
- 数值只取自页面实际文本，禁止编造或脑补；行未渲染数字 = 先滚动/等待，而不是补 0。

## 约束
- 登录、跳转、抓取都属于对真实外部站点的操作：先让用户完成扫码登录；只读取页面展示的数据，不修改剧集、不发表内容、不提交表单。
- 用户没明确授权时，输出 Excel 存到桌面即可，不要上传/分享到任何第三方。
- 换电脑执行时，会话/登录态不存在，需重新扫码登录；skill 内容不依赖某台机器的固定标签页或路径。
